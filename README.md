# AI Voice Assistant with Flask & Google AI

This project builds a **real-time AI-powered voice assistant** using **Python, Flask, and Google Generative AI**. It integrates speech recognition to process user queries and provide intelligent responses dynamically, ensuring a seamless and interactive user experience.

```
│── app.py          # Flask backend
```

---

## **🚀 Overview**  

This project demonstrates how to create a real-time AI voice assistant that listens, processes, and responds to user queries using **Google Generative AI**.  

### **Features:**  
👉 **Real-Time Voice Input** - Speak to the assistant using a microphone.  
👉 **AI-Powered Responses** - Get smart, context-aware answers.  
👉 **Dynamic Conversation History** - View chat interactions in real-time.  
👉 **Speech Synthesis** - The AI responds audibly.  
👉 **Web-Based UI** - Built with Flask, JavaScript, and Tailwind CSS.  

---

## **🔧 Technologies Used**  

- **Python & Flask** - Backend server to handle requests.  
- **Google Generative AI** - Generates intelligent responses.  
- **JavaScript** - Handles speech recognition & UI updates.  
- **HTML/CSS (Tailwind CSS)** - Creates a modern, responsive UI.  
- **SpeechRecognition API** - Converts user voice to text.  
- **SpeechSynthesis API** - Converts AI responses to speech.  

---

## **🛠 How It Works**  

1. **User Speaks** - Click the mic button, and the browser captures your voice.  
2. **Processing** - The speech is sent to Flask, where Google AI generates a response.  
3. **Dynamic UI Update** - The response appears in the chat.  
4. **AI Speaks** - The assistant reads out the response using speech synthesis.

## **⚡ Installation**  

### **Prerequisites**  

🔹 **Python 3.x**  
🔹 **Google Cloud API Key** (for Google Generative AI)  
🔹 **Node.js** (for front-end dependencies)  

### **Steps to Run Locally**  

```bash
# Clone the repository
git clone https://github.com/Mohammed-razin-cr/AI-Voice-Assistant.git

# Navigate to the project folder
cd AI-Voice-Assistant

# Install dependencies
pip install -r requirements.txt

# Run the Flask server
python app.py
```

> Access the web app at **[http://localhost:5000](http://localhost:5000)** 🎧
